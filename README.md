# Minha Página

Uma página web moderna e responsiva criada do zero.

## Arquivos

- **index.html** - Estrutura da página
- **style.css** - Estilos e layout responsivo
- **script.js** - Funcionalidades interativas

## Características

✅ Design responsivo (mobile-friendly)
✅ Navegação com scroll suave
✅ Header fixo
✅ Seções organizadas
✅ Footer

## Como usar

1. Abra o arquivo `index.html` em um navegador
2. Clique nos links de navegação para explorar
3. Customize o conteúdo conforme sua necessidade

## Personalização

- Edite o conteúdo em `index.html`
- Altere cores e estilos em `style.css`
- Adicione funcionalidades em `script.js`

Divirta-se desenvolvendo! 🚀
